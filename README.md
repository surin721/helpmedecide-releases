# Help Me Decide — Releases

Downloadable builds of **Help Me Decide**, an Android app that helps people with
executive dysfunction (ADHD and similar) get started on tasks via a lock-screen
check-in and a short decision flow to one small strategy.

This repository holds **binaries only** — no source code. Grab the latest APK
from the [Releases](../../releases) page and sideload it (enable "Install from
unknown sources" for your browser/file manager, then open the downloaded APK).
